社内活用事例

実際にこんな使い方をしています

専門的な知識は不要です。日本語で話しかけるだけで、こんなことができるようになりました。

1
定期納品管理システム
毎日1〜2時間 → 約3分
エクセルでカレンダーを手作成し、1件ずつ通販天国へ入力していた
→
顧客マスタに条件を入力するだけでカレンダーが自動生成。発注予定表をコピペして完了
20〜80件の注文管理がコピペ1回で完了するようになりました。
📊 制作物を見る
2
アポインターシフト管理
毎日20〜30分 → 約3分
18名がチャットワークで文章を送信 → 柳下さんがエクセルに手入力してPDF共有
→
18名がフォームでボタン選択するだけ。スプレッドシートに自動集約されるので共有も簡単
入力する側も集計する側も、手間がかなり減りました。
📋 入力フォーム 📊 管理表を見る
3
アポインター実績ダッシュボード
月3時間 → 約3分
セールスフォースのデータを島田さんがアポインターごとに手入力していた
→
データをコピペするだけで、目標対比・ランキングが自動で更新される
各アポインターの実績が見える化され、その日のトップもわかるようになりました。
📊 制作物を見る
4
小口現金処理システム
都度20分〜1時間 → 最大5分
領収書を見ながら出納帳を手作成し、枚数分の振替伝票を1枚ずつ手入力
→
領収書を撮影してスプレッドシートに取り込み、確認後にボタン1つで完成
転記ミスなどのヒューマンエラーも防げるようになりました。
📊 制作物を見る
5
関東エリア お米市場価格調査レポート
調査・集計・資料作成が一括で完了
各スーパーのチラシや価格を手作業で調べ、エクセルにまとめて資料化していた
→
「関東エリアのお米市場価格を調べてWord・Excelレポートにまとめて」と伝えるだけで完成
銘柄別の価格比較・相場分析・戦略提言まで含むレポートが自動で作成されます。
📄 レポートを見る

Claude（クロード）とは

日本語で話しかけるだけで
動く、AIアシスタントです。

Anthropic社が開発した次世代AIです。
文章を書く、資料をまとめる、表を作る、計算する——
普通の日本語で指示するだけで対応してくれます。

  • メール・議事録・報告書の下書き作成
  • Excelの数式・マクロの作成サポート
  • 資料・PDFの要約・分析
  • アイデア出し・企画のブレスト
  • 市場調査レポートの自動作成
  • スプレッドシートや管理ツールの構築
